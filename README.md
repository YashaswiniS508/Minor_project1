# Minor_project1
A Python-based behavioral analysis tool that parses raw WhatsApp chat exports to extract engagement metrics, activity heatmaps, word frequencies, and user archetypes.
📌 Overview
This project transforms unstructured text logs from WhatsApp exports into structured datasets to perform Exploratory Data Analysis (EDA). Without relying on heavy external data-wrangling frameworks, the script demonstrates core Python operations, string parsing algorithms, date-time manipulation, and matrix-based heatmap generation using NumPy.
🛠️ Tech Stack & Dependencies
Language: Python 
  Core Libraries: 
  * `numpy` – Matrix generation and heatmap scaling
  * `datetime` – Timestamp parsing and time-delta arithmetic
